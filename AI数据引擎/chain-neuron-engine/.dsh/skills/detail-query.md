# 明细查询

适用于“明细、记录、单据、哪些商品、业务情况”等需要列出具体记录的问题。

## 执行规则

1. 使用 `engine_records_query`，不要用明细结果自行计算汇总。
2. 先识别时间、组织层级一、组织层级三、定位单元、产品和支付方式条件。
3. 对用户说法不确定时，先调用 `engine_level_values` 查询引擎真实值，再提交明细查询。
4. 使用分页参数控制返回规模；需要更多数据时按页查询。
5. 回答中说明筛选条件、总记录数、当前页范围和关键字段。
6. 结果中有 `route` 时，保留路由节点、命中和剪枝信息供 Harness 展示。
7. 不能把部分页面结果表述为全量结果。
