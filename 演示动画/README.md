# 智慧树查询原理动画

本目录是发布副本中的独立产品演示模块。它使用 Remotion 生成一段不依赖真实业务数据的动画，帮助首次接触项目的读者理解查询如何经过统一基座、多个数据集智慧树、汇总节点和统一输出。

动画不会参与系统运行，也不会读取 SQLite、Excel、CNTS 段文件、附件或模型密钥。

## 演示口径

动画中的树、数据集名称、分枝和计数均为拓扑说明，不是业务数据或真实查询结果。它严格遵循系统的架构边界：

```text
用户问题入口
  -> 统一基座：过滤、翻译、赋能、纠偏
  -> 选择参与的数据集智慧树
  -> 中通内链：时间与共有特征定位
  -> 中通周存：读取物化聚合块
  -> DNA 外链：非共有特征、分枝与继续下钻
  -> 各数据集独立结果
  -> 合并 / 汇总节点
  -> 一个统一输出
```

分枝仅在时间层数据量超过阈值时，按确认后的共有维度递归生长，例如 `组织层级一 -> 组织层级二 -> 组织层级三 -> 定位单元 -> 产品类别`。动画将其画成从主干侧向生长的路径，不把它误表示为一个孤立方块。

## 分镜

| 时段 | 画面 | 说明 |
| --- | --- | --- |
| 0-4 秒 | 用户问题进入统一基座 | 基座将自然语言转成标准时间、组织、产品和指标参数。 |
| 4-10 秒 | 多棵智慧树从基座向上生长 | 每个事实数据集是独立树，共享语义基座。 |
| 10-19 秒 | 三层数据路径被点亮 | 中通内链进、中通周存过、DNA 外链出。 |
| 19-26 秒 | 分枝按维度侧向生长 | 只有超阈值时间层按确认的维度继续聚合。 |
| 26-32 秒 | 各数据集结果合并后统一输出 | 总量可按确认口径合并，分项则并列保留。 |

## 本地预览与渲染

要求：Node.js 20+、npm，以及 Remotion 兼容的本机浏览器环境。

```powershell
Set-Location .\演示动画\remotion
npm ci
npm run studio
```

渲染发布成片与封面：

```powershell
npm run render
npm run still
```

输出在 `演示动画/预览/`。提交 GitHub 时仅提交：

- `智慧树查询原理.png`：README 封面；
- `智慧树查询原理.mp4`：720p H.264 成片，建议控制在 20MB 内；
- `remotion/` 下的源码和 `package-lock.json`。

不要提交 `node_modules`、渲染缓存、逐帧导出、多个编码版本或真实数据。若正式视频超过 GitHub 的常规文件体积边界，应把成片发布到 GitHub Releases，仓库只保留封面、源码和下载链接。
